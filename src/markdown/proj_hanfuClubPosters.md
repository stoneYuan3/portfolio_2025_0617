# Poster Design for Hanfu and Sinology Club

### Intro

This is a series of posters I designed for the Vancouver Hanfu Culture Association club and the UBC Student Association of Sinology. The main tools used include Figma *(poster design)*, Photoshop *(image editing)* and Midjourney *(generating image assets).*
